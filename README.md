## Engineering / Technical Projects

- **RIT Racing Electronics Team**

  > Battery Management System Test Board: Designed in Altium Professional for easy testing/debugging of F35's Battery Management System; Essentially a couple potentiometers, long voltage dividers, and distributed breakout points for testing individual battery cells and temp sensors on the main board.
  >
  > F26 Re-Harnessing: In between my BMS Test Board and RML/TSSI project I temporarily worked on helping start the process of creating a new harness for the restoration of a legacy car (F26). Worked with RapidHarness, Wiring Diagrams, and wire routing.
  >
  > PCB Vibration Testing Unit: Finishd Development and Implementation of Testing Unit, returned to later in the semester for organizational/longevity improvements. Primary Components include ESP32, 4x4 Membrane Keypad, 20x4 LCD Screen, Perfboard voltage divider, 3D printed electronics enclosure, mounting plate for UUT.
  >
  > RML/TSSI Custom PCB: Custom PCB design for improved Ready to Move Lights, and Tractive System Status Indicator. I worked on my this project by myself with guidance from the team's electronics manager, and brought it up to the PCB development state before the end of the semester. Researched and chose specific components for the board based on size, power, longevity, cost, and other relevant metrics. Performed all power calcs and designed circuit structure for PCB. Created Altium Schematic files just before end of semester.
  >
  > Skills Summary: Altium Schematic Design + PCB Layout Design, Version Control + Collaborative features in Altium; Debugging + Development with Multimeter, Oscilloscope, etc; C/C++, Arduino IDE, Soldering with ESP32, Perfboard Soldering, Efficient Wire Routing; RapidHarness, Wiring Diagrams/Documentation, Datasheet analysis + component selection, Power Calculations, Circuit Design.
